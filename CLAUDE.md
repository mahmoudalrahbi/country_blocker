## Architecture

Feature-first Clean Architecture with three layers per feature:

- **Domain** — pure Dart: entities, abstract repository interfaces, use cases (each in its own file, one public method `call()`)
- **Data** — implementations: models (DTOs with JSON), local data sources (SharedPreferences), repository impls
- **Presentation** — Riverpod `StateNotifier`s, screens, widgets

The only feature is `lib/features/country_blocking/`. Shared screens and services live in `lib/shared/`.

**Dependency injection**: All Riverpod providers are declared in a single file — `lib/core/providers.dart`. Do not define providers inside feature files; always add them here.

**Data flow**: UI → Notifier → UseCase → Repository → DataSource → SharedPreferences. Results propagate back as `Either<Failure, T>` (dartz).

**State**: Notifier state classes use Freezed for immutability (see `country_blocking_state.dart`). Run build_runner after editing `@freezed` classes.

**Freezed v3 requirement**: All `@freezed` classes must be declared as `abstract class`, not plain `class`. Omitting `abstract` causes a compile error because the generated mixin defines abstract getters the class must satisfy.

## Native Call Blocking

**Android**: `CallBlockingService.kt` implements `CallScreeningService`. It reads blocked countries from SharedPreferences (key `flutter.blocked_countries_simple`, JSON string) and uses `libphonenumber` for parsing. The service must hold `ROLE_CALL_SCREENING` — requested via `MainActivity.kt` MethodChannel.

**iOS**: Requires a manual CallKit `CallDirectoryExtension` target — see `ios_setup_instructions.md`. iOS can only block exact numbers, not prefixes/country codes.

**SharedPreferences keys shared between Flutter and native**:
| Key | Type | Purpose |
|-----|------|---------|
| `flutter.blocked_countries` | StringList | Flutter format |
| `flutter.blocked_countries_simple` | JSON string | Native Android format |
| `flutter.blocking_enabled` | Boolean | Global on/off |
| `flutter.blocked_calls_count` | Integer | Stats counter |
| `flutter.blocked_call_logs_native` | JSON array | Call log entries |

## Localization

Supports English and Arabic. ARB files are in `lib/l10n/`. Run `flutter gen-l10n` (or `flutter pub get`) to regenerate. Use `AppLocalizations.of(context)!` — never hardcode user-visible strings (custom_lint enforces this).

## Development Workflow

**Test-Driven Development (TDD) is required for all work:**

1. Write tests BEFORE implementing any new feature or fix.
2. Tests must clearly define expected behavior.
3. Only write implementation code after tests are in place.
4. Run the full test suite after implementation: `flutter test`
5. All tests MUST pass before the task is considered complete.
6. If any test fails, fix the code — never skip, bypass, or weaken tests.
7. Work in small increments and validate frequently.

## Test Structure

Tests mirror the `lib/` folder structure under `test/`:

```
test/
├── core/utils/                          # Shared utility tests
├── features/country_blocking/
│   ├── data/
│   │   ├── datasources/                 # Local data source tests
│   │   └── repositories/               # Repository impl tests
│   ├── domain/usecases/                 # One test file per use case
│   └── presentation/
│       ├── notifiers/                   # StateNotifier tests
│       └── screens/                     # Widget tests
└── utils/                               # Misc utility tests (e.g. country flags)
```

- Mock files (`*.mocks.dart`) are auto-generated by `build_runner` — do not edit manually.
- Use `MockCountryBlockingRepository` from `get_blocked_countries_test.mocks.dart` when writing new domain use case tests (it already covers the full repository interface).
- Use `MockCountryBlockingLocalDataSource` from `country_blocking_repository_impl_test.mocks.dart` for repository impl tests.

## Key Files

- `lib/core/providers.dart` — all DI providers (start here to understand the dependency graph)
- `lib/main.dart` — app init; overrides `sharedPreferencesProvider` in `ProviderScope`
- `lib/features/country_blocking/presentation/notifiers/country_blocking_notifier.dart` — main business logic controller
- `android/app/src/main/kotlin/com/mahmoudalrahbi/countryblocker/CallBlockingService.kt` — Android call screening
